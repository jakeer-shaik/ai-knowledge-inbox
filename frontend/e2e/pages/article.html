Connection Pooling Guide

PgBouncer sits between the application and Postgres and keeps a small pool of server connections open. In transaction pooling mode a server connection is assigned to a client only for the duration of a transaction.

Size the application pool per instance so that instances multiplied by pool size stays below max_connections. Prepared statements do not survive transaction pooling, so disable them in the database driver.

Monitor the waiting clients metric: if it grows, the pool is too small or transactions are too long.
